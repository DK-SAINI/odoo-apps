Float Time Second Widget

Custom Odoo 20 widget to input and display float fields in HH:MM:SS format

Overview

The Float Time Second Widget is a custom field widget for Odoo 20 that allows users to input and display float time values in HH:MM:SS format. It is designed to enhance precision in time tracking, useful in attendance, timesheet, or time-based billing applications.

Key Features

  • ⏱ Input float time with hours, minutes, and seconds (HH:MM:SS).
  • 🔁 Converts between float and human-readable time automatically.
  • 🧩 Easy integration using the widget name float_time_second.
  • 🦉 Built using Odoo 20’s modern OWL framework.
  • ✅ Works with readonly and editable fields.

Installation

  1. Copy the module to your Odoo 20 custom addons directory.
  2. Update the App list in developer mode and install Float Time Second Widget.

Usage

To use the widget, simply apply it to any float field in your XML view:

<field name="duration" widget="float_time_second"/>
